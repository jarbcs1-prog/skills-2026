- **Base URL:** `https://opencode.ai/zen/v1`
- **Chat Completions:** `https://opencode.ai/zen/v1/chat/completions`
- **Models:**
    - `opencode/big-pickle` (Big Pickle)
    - `opencode/north-mini-code-free` (North Mini Code Free)
    - `opencode/nemotron-3-ultra-free` (Nemotron 3 Ultra Free)
    - `opencode/deepseek-v4-flash-free` (Deepseek V4 Flash Free)
    - `opencode/mimo-v2.5-free` (Xiaomi MiMo V2.5 Free)
	- `opencode/ling-3.0-flash-free` (Ling 3.0 Flash Free)
